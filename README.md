**Русский** | [English](README.en.md)

**Аналог Pixelmator Pro для macOS: фоторедактор со слоями на Swift (AppKit + Metal).**

## Что это

Nativ Pro — аналог Pixelmator Pro: профессиональный фоторедактор для macOS с такой же раскладкой и логикой работы.
Слева панель слоёв, по центру холст, справа параметры инструмента и полоса инструментов.

Сейчас проект на **раннем этапе**: интерфейс и ядро уже есть, инструменты рисования и коррекции подключаются
по очереди.

### Уже работает

- **Документ со слоями.** Растровые слои, группы, маски, непрозрачность, 28 режимов наложения, история правок
  (отмена/повтор).
- **Свой формат `.pedoc`.** Zip-пакет с базой SQLite и плитками пикселей (8 и 16 бит на канал), превью для Finder.
  Неизменённые картинки хранятся исходным файлом, без перекодирования.
- **Рендер.** На Metal для окна, на CPU как эталон для тестов. Результаты двух рендеров сверяются тестами.
- **Окно редактора.** Панель слоёв (перетаскивание, переименование, видимость), холст с масштабом, полоса из 21
  инструмента и панели их параметров, заголовок окна с масштабом и быстрыми действиями.
- **Меню на русском и английском** с клавиатурными сокращениями. Язык выбирается по системе.
- **Файлы.** Открытие PNG, JPEG, HEIC, TIFF, GIF, WebP. Экспорт в PNG, JPEG, TIFF, HEIC. Вставка из буфера
  обмена, импорт картинок слоями, автосохранение.
- **Консольная утилита `pe`** для ядра: рендер, замеры скорости и памяти на больших документах, сравнение PNG.

### В работе

Кисти, заливка, ластик, выделения, текст, фигуры, кадрирование, цветокоррекция и эффекты: панели уже есть,
сами операции подключаются этап за этапом.

## Сборка

Нужны **macOS 26** и **Xcode 26** (Swift 6).

```bash
git clone https://github.com/Vitaliy-vibe/nativ-pro.git
cd nativ-pro
./tools/build_app.sh            # собрать .build/app/PhotoEditor.app и запустить
./tools/build_app.sh --no-run   # только собрать
swift test                      # тесты
```

Ядро (`EditorCore`, `EditorApp`, `pe`) собирается и тестируется и на Linux. Окно на AppKit есть только на macOS.

## Устройство

| Модуль | Что внутри |
|---|---|
| `EditorCore` | модель документа, плитки, история, PNG, формат `.pedoc`, эталонный рендер на CPU |
| `EditorRenderMetal` | рендер на Metal и Core Image |
| `EditorApp` | логика окна без AppKit: меню, команды, масштаб (проверяется тестами) |
| `PhotoEditor` | приложение macOS на AppKit |
| `pe` | консольная утилита ядра |
| `CSQLite`, `CZlib` | встроенная SQLite и системная zlib |
